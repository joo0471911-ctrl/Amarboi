অফলাইনে অ্যাপ ও সাউন্ড চালানোর গাইড
====================================

কেন আগে অফলাইনে সাউন্ড বাজত না?
  পেজটা ঠিকই খুলত, কিন্তু সাউন্ড আসে ফোনের নিজস্ব ভয়েস (Google Text-to-speech) থেকে।
  অনেক ফোনে বাংলা ও আরবি ভয়েস শুধু ইন্টারনেট থেকে আসে। নেট গেলে সাউন্ডও যায়।
  আর অ্যাপ আগে প্রথম পাওয়া ভয়েসটাই নিত, সেটা অনেক সময় নেট-নির্ভর। এবার ঠিক করা হয়েছে:
  অ্যাপ এখন অফলাইন-সক্ষম (লোকাল) ভয়েসকে আগে বেছে নেয়।

ধাপ ১ (সবচেয়ে জরুরি, একবার): ফোনে বাংলা ও আরবি ভয়েস ডাউনলোড
  ইন্টারনেট চালু রেখে:
  Settings -> Accessibility -> Text-to-speech output
  (স্যামসাং: Settings -> General management -> Language -> Text-to-speech)
  গুগলের ইঞ্জিনের পাশে ⚙ -> Install voice data
  -> Bengali (Bangladesh), Arabic এবং English ডাউনলোড করুন।
  শেষে ব্রাউজার বন্ধ করে আবার খুলুন।
  অ্যাপের "স্লাইড বারের নিচের চিপ" দেখাবে:
    ✅ অফলাইনে সাউন্ড প্রস্তুত     = সব ঠিক আছে
    ⚠ অফলাইন ভয়েস নেই: বাংলা...   = চিপে ট্যাপ করলে ধাপগুলো ও পরীক্ষার বাটন আসবে

ধাপ ২: পেজ ইন্টারনেট ছাড়া খোলা
  * ফোনের ফাইল থেকে খুললে (content://...): পেজ সবসময় অফলাইনে খোলে।
  * Netlify লিংক থেকে খুললে: একবার নেট দিয়ে পুরো খুললে ফোনে সংরক্ষিত হয়ে যায়
    (sw.js এই কাজ করে)। পরে নেট ছাড়াই খুলবে। Chrome মেনু -> Add to Home screen
    দিলে অ্যাপের মতো আইকন পাবেন।
  * Netlify-তে আপলোডের সময় এই ফোল্ডারের সব ফাইল একসাথে দিন:
    index.html, sw.js, manifest.webmanifest, icon.svg, audio/, tools/

ঐচ্ছিক (সবচেয়ে নিশ্চিত): mp3 সাউন্ড প্যাক
  কম্পিউটারে একবার: pip install edge-tts   তারপর   python tools/make_audio.py
  audio/ ফোল্ডারে ৪৩২টি mp3 তৈরি হবে। ফোনের ভয়েসের উপর নির্ভর করতে হবে না।
  (আপডেটের পর sw.js এর CACHE = "kids-learning-v7" এর সংখ্যা বাড়ান।)

সাউন্ডের অগ্রাধিকার: ১) আপনার রেকর্ড করা ভয়েস  ২) audio/ এর mp3  ৩) ফোনের ভয়েস
