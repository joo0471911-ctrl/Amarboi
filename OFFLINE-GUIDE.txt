অফলাইনে শিশুদের সাউন্ড চালানোর ধাপ
=====================================

কীভাবে কাজ করে (অগ্রাধিকার ক্রমে)
  ১) আপনার নিজের রেকর্ড করা ভয়েস (পেজের রেকর্ড বাটন)
  ২) audio/ ফোল্ডারের mp3 সাউন্ড প্যাক   <- এটাই অফলাইনে নিশ্চিত চলে
  ৩) ফোনের নিজস্ব ভয়েস (অনেক ফোনে নেট ছাড়া বাংলা/আরবি চলে না)

ধাপ ১: সাউন্ড তৈরি (একবার, নেট লাগবে, কম্পিউটারে)
  pip install edge-tts
  python tools/make_audio.py
  -> audio/ ফোল্ডারে ৪১৬টি mp3 তৈরি হবে।

ধাপ ২: ফোল্ডারটি ওয়েবসাইটে আপলোড (HTTPS দরকার)
  index.html, sw.js, manifest.webmanifest, icon.svg, audio/, tools/ -> সব একসাথে
  (GitHub Pages, Netlify, Cloudflare Pages ইত্যাদিতে ফ্রি হোস্ট করা যায়)

ধাপ ৩: শিশুর ফোন/ট্যাবে একবার নেট দিয়ে খুলুন
  পেজ খুললে সব ফাইল নিজে থেকে ফোনে সেভ হয়ে যায়।
  তারপর Chrome মেনু -> "Add to Home screen / Install app"।

ধাপ ৪: পরীক্ষা
  ফোনে Airplane mode অন করে অ্যাপটি খুলে কয়েকটা সাউন্ড বাজান।

সাউন্ড বদলালে: audio/ এর ফাইল বদলে sw.js এর প্রথম দিকের
  CACHE = "kids-learning-v4" কে v2 করুন, না হলে পুরনো সাউন্ড ক্যাশে থাকবে।
