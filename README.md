# শিশুদের বাংলা, ইংরেজি, গণিত ও আরবি শিক্ষা অ্যাপ (v4)

এই আপডেটে আপনার সবগুলো চাহিদা যুক্ত করা হয়েছে:
1. ভয়েস চেঞ্জের যোগফল যাচাই (Parental Math Gate) বাদ দেওয়া হয়েছে।
2. বাংলা, ইংরেজি ও আরবি নেটিভ ভয়েস সিলেকশন ও পূর্ণ বাক্য/আয়াত উচ্চারণ যুক্ত করা হয়েছে।
3. সূরা আল-ফাতিহার পূর্ণ ৭ আয়াতসহ সব সূরার আয়াত কার্ড ও ফুল-স্ক্রিন পপ-আপে দেখানো হয়েছে।
4. বড় ফুল-স্ক্রিন পপ-আপ ডিসপ্লে ও জাভাস্ক্রিপ্ট স্ট্রিং ফিক্স যুক্ত করা হয়েছে।
