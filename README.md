# শিশুদের বাংলা, ইংরেজি, গণিত ও আরবি শিক্ষা অ্যাপ

এই প্রজেক্টটিতে নিচের বিষয়গুলো যুক্ত করা হয়েছে:
- **স্বরবর্ণ (অ - ঔ)** ও **ব্যঞ্জনবর্ণ (ক - ঁ)**
- **গাণিতিক সংখ্যা (১ - ১০০ / 1 - 100)**
- **নামতা (১ থেকে ২০-এর ঘর)**
- **ইংরেজি অ্যালফাবেট (A - Z)**
- **আরবি হরফ (ا - ي)**
- **কোরআনের সূরা (সূরা আল-ফাতিহা ও শেষ ১০টি সূরা: সূরা আল-ফীল থেকে সূরা আন-নাস)**

## প্রধান সুবিধা
1. **টপ-ডাউন মেনু ও কুইক-সিলেক্ট বক্স:** সহজেই যেকোনো বিষয় বা ঘর নির্বাচন করা যায়।
2. **সব প্লে / পজ / বন্ধ কন্ট্রোল:** এক ক্লিকে ধারাবাহিকভাবে সবগুলো শোনা, পজ করা বা বন্ধ করা যায়।
3. **ফুল-স্ক্রিন পপ-আপ:** প্রতিটি কার্ডে ট্যাপ করলে বড় আকারে অক্ষর/সংখ্যা/সূরা ও উদাহরণ দেখা যায়।
4. **অভিভাবক লক ও নিজের ভয়েস রেকর্ডিং:** গণিতভিত্তিক অভিভাবক যাচাইকরণের মাধ্যমে নিজের কণ্ঠ রেকর্ড ও সংরক্ষণ (IndexedDB) করা যায়।

## GitHub-এ আপলোড করার নিয়ম
1. জিপ ফাইলটি আনজিপ করুন।
2. আপনার GitHub রিপোজিটরিতে `kids_learning_app` ফোল্ডারের ফাইলগুলো (`index.html`, `README.md`) আপলোড করুন।
3. **Settings → Pages** থেকে Branch `main` সিলেক্ট করে Save করলে অ্যাপটি লাইভ চলবে।
