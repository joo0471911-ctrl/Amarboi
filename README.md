# শিশুদের বাংলা, ইংরেজি, গণিত ও আরবি শিক্ষা অ্যাপ (v5)

এই আপডেটে যুক্ত হয়েছে:
1. **পরিচ্ছন্ন ও সুসংগঠিত হোম/হিরো সেকশন:** স্পষ্ট টাইপোগ্রাফি, সারসংক্ষেপ কার্ড এবং সুবিন্যস্ত বিষয় ট্যাব ও ফিল্টার।
2. **আরও বড় ফুল-স্ক্রিন পপ-আপ লেখা:** অক্ষর, সংখ্যা, হরফ, হেডলাইন ও সাবলাইন আরও বড় ফন্টে দেখানো হয়েছে।
3. **সব আরবি সূরার বাংলা অনুবাদ:** সূরা আল-ফাতিহা ও শেষ ১০টি সূরার প্রতিটি আরবি আয়াতের সাথে বাংলা অনুবাদ দেখানো হয়েছে।
4. **প্রফেশনাল ওয়েব ডিজাইন:** সামঞ্জস্যপূর্ণ কালার প্যালেট, কার্ড লেআউট ও স্টিকি প্লেয়ার বার।
